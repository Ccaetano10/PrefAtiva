
# PrefAtiva

<p align="center">
  Uma plataforma web para aproximar cidadãos e prefeituras na identificação e resolução de problemas urbanos.
</p>

---

## Sobre o Projeto

O **PrefAtiva** é uma plataforma web desenvolvida com o objetivo de facilitar a comunicação entre cidadãos e administrações municipais, permitindo o registro, acompanhamento e gerenciamento de problemas urbanos.

Através da plataforma, os cidadãos podem registrar situações que afetam a infraestrutura e a qualidade de vida da população, como buracos nas vias públicas, iluminação danificada, descarte irregular de lixo, problemas de sinalização, entre outras ocorrências.

O sistema busca direcionar cada ocorrência à prefeitura responsável, considerando sua localização, facilitando a organização e o acompanhamento das solicitações.

## Objetivos

- Facilitar a comunicação entre cidadãos e prefeituras.
- Permitir o registro de problemas urbanos.
- Identificar a prefeitura responsável por cada ocorrência.
- Proporcionar transparência no acompanhamento das solicitações.
- Auxiliar as administrações municipais no gerenciamento das ocorrências.

## Funcionalidades

### Cidadão

- Realizar cadastro e autenticação na plataforma.
- Registrar problemas urbanos.
- Selecionar a categoria da ocorrência.
- Adicionar descrição e fotografias.
- Informar a localização do problema.
- Acompanhar o andamento das solicitações.
- Consultar o status das ocorrências registradas.

### Administração

- Visualizar ocorrências registradas.
- Consultar informações e localização dos problemas.
- Gerenciar solicitações recebidas.
- Encaminhar ocorrências aos responsáveis.
- Atualizar o status das ocorrências.
- Acompanhar os problemas registrados pela população.

## Fluxo de Funcionamento

1. O cidadão registra um problema urbano na plataforma.
2. Informa a categoria, descrição e localização da ocorrência.
3. O sistema identifica a prefeitura responsável pela região informada.
4. A ocorrência é armazenada e disponibilizada para gerenciamento.
5. A administração responsável analisa a solicitação e atualiza seu andamento.
6. O cidadão acompanha as atualizações pela plataforma.

## Status das Ocorrências

| Status | Descrição |
|---|---|
| Pendente | Ocorrência registrada e aguardando análise. |
| Em análise | Ocorrência sendo avaliada pela administração responsável. |
| Em andamento | Problema com atendimento ou resolução em andamento. |
| Concluído | Ocorrência atendida e finalizada. |

## Banco de Dados

O banco de dados do PrefAtiva é estruturado para organizar as principais informações da plataforma, contemplando entidades como:

- Usuários
- Ocorrências
- Categorias
- Prefeituras
- Fotografias das ocorrências
- Status das solicitações

## Tecnologias Utilizadas

- **HTML5** – Estruturação das páginas.
- **CSS3** – Estilização e layout da aplicação.
- **JavaScript** – Interatividade e funcionalidades.
- **PHP** – Desenvolvimento da lógica e processamento no servidor.
- **SQL** – Manipulação e gerenciamento do banco de dados.

## Desenvolvimento

O PrefAtiva é um projeto acadêmico desenvolvido como Trabalho de Graduação (TG/TCC), com foco no desenvolvimento web, modelagem de banco de dados e aplicação de soluções tecnológicas para problemas urbanos.
